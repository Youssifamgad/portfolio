# Yousef Amgad — Engineering Portfolio

An English portfolio showcasing industrial automation, robotics, embedded systems and AI workflows.

Static HTML, CSS and JavaScript. Includes five project case studies, original galleries, two video demonstrations, experience, training, certifications and a downloadable CV.

## Preview

Serve this directory with any static HTTP server. No build step or dependencies are required.

## Hosting

GitHub Pages: deploy the main branch from the repository root.

## Accessibility & performance

Responsive layouts, keyboard-accessible image dialogs and navigation, lazy-loaded images, user-initiated video playback, and reduced-motion support.
